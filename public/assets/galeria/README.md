# Galeria fotográfica

A galeria da landing usa as oito fotografias autorais enviadas pelo autor em `galeria_comp(1).rar`.

As imagens foram convertidas para WebP, ajustadas para **4:3 (1080 × 810 px)** e preservam o tratamento original em preto e branco. Os cantos arredondados são aplicados por CSS, sem alterar os arquivos.

A ordem e os textos alternativos de acessibilidade estão em `GALLERY_PHOTOS`, no arquivo `src/App.tsx`. As fotografias são navegáveis pelo carrossel e podem ser ampliadas em um diálogo com as setas de navegação e a tecla Esc.
