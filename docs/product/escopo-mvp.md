# Escopo da primeira versão

Este documento delimita o que faz parte da primeira versão publicável do portfólio. Não é uma lista de funcionalidades futuras para desenvolver imediatamente.

## Incluído

| Área | Entrega |
| --- | --- |
| Landing | Apresentação, projetos, áreas, tecnologias, Fragmentos, trajetória, Sobre mim com galeria e contato |
| EduComp | Página de estudo de caso com contexto, fluxos, processo e galeria de quatro espaços |
| Fragmentos | Página de ensaio com índice de leitura e conteúdos relacionados |
| Navegação | Cabeçalho fixo, links entre páginas e retorno às seções da landing |
| Interações | Carrosséis, microinterações e modal de contato |
| Dispositivos | Layout adaptável para desktop, tablet e celular |
| Metadados | Títulos, descrições, favicon e regras de indexação por rota |

Os quatro espaços reservados da galeria do EduComp e os cards de projetos e publicações futuras fazem parte do estado atual da interface. Não devem ser apresentados como projetos ou artigos concluídos.

## Pendências antes de publicar

- Conferir os links de LinkedIn e GitHub.
- Adicionar o PDF do currículo em `public/curriculo-pedro-albuquerque.pdf`.
- Substituir a imagem provisória do ensaio pela fotografia prevista no Figma.
- Selecionar e inserir as quatro capturas reais do EduComp, quando disponíveis.
- Revisar os trechos demonstrativos e decidir o que ficará público.
- Executar os testes funcionais e o build completo.
- Configurar a URL pública e verificar os metadados após a publicação.

## Fora do escopo

Não há cadastro de usuários, banco de dados, CMS, formulário que envie dados a um servidor ou área administrativa. Adicionar novos projetos e textos ainda exige alterações no código.

Se o volume de publicações crescer, a forma de armazenar conteúdo pode ser revista. Isso não é necessário para a primeira publicação.
